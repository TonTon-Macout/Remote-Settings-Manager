# Remote Settings Manager

### Приложение для поиска в локальной сети и отображения вебморды устройств
+ с установленной библиотекой [Settings AlexGyver](https://github.com/GyverLibs/Settings) 
+ с установленным [WLED](https://github.com/wled/WLED?ysclid=m7q4g9kdu7478403852)
+ [Home Assistant](https://github.com/home-assistant)
+ любых устройсв с доступным веб интерфейсом (роутеры, принтеры, самоделки etc.)
+ и вебморд устройств добавленных вручную, в.т.ч. и с доступом из сети интернет </br></br>

## Возможности приложения:
Б - [Безопасность  ↓](#safety)
+ Поиск в локальной сети и отображение устройств, с  **Settings**, **WLED**, **Home Assistant**, любых других доступных вебинтерфейсов
  + добавление веб-интерфейсов устройств вручную
    - можно добавить сайт, надпример alexgyver.ru и добавить его как устройство
+ Удобное переключение между устройствами
+ Ярлык с именем открытого устройсва
  + можно перемещать вверх вниз по экрану свайпом влево
  + жестом вправо можно задвинуть, если мешает имя
+ Список устройсв находится в выдвигающейся снизу слайдпанели
  + выдвигается по клику на ярлык, а если он отключен то по кнопке или жесту назад
+ Автоопределение подсети
  + можно ввести вручную  
+ Возможность переименовать устройства
+ Несколько тем приложения
-------------------------
+ Режим разделения устройств по сетям (начианая с версии 1.2.0)
+ <b>Разделение автоматически:</b>
  + Будет определять сеть к которой подключены и показывать устройства из этой сети.
  + Отдельно определяет сотовую сеть, для устройств доступных из интернета (сюда устройства необходимо добавлять вручную)
  + Можно добавлять сети вручную, для организации списков устройств.
  + 🧭 Для этого режима нужно разрешение на доступ к местоположению и включеная геолокация. Без этого андроид не даст определить ssid и мак адрес роутера.
    + RSM не получает данные о местоположении, эти разрешения нужны только для получения ssid и bssid сети
+ <b>Разделение вручную:</b>
  + Просто вручную созданные списки устройств. вручню создали, вручную переключаем.
  + Для этого режима разрешения и включеная геолокация не нужны.
  
<h2 id="safety" >Безопасность:</h2>

  + ⚠️ RSM это пульт управления вашими устройствами, а не браузер, он не предназначен для серфигна в интернете!
    - Несмотря на то что вы можете открывать и добавлять любой внешний веб сайт, как alexgyver.ru, sberbank.ru, фишинговую копию вашего банка, все что захотите.
      RSM не гарантирует безопасного хранения данных, RSM выполняет все java-скрипты на открытых сайтах, сохраняет куки между сессиями.
    - Программа изначально создана с расчётом, что вы используете её **только в своей домашней сети** и открываете только свои доверенные устройства!
    - Самая плохая идея из возможных, это достать смарт в общественном месте, увидев вафлю без пароля и с криком "халява приди" подключиться к ней, открыть сбербанк в приложении RSM чтобы срочно проверить баланс. Впрочем это крайне дурацкая идея и без RSM. Вы должны об этом всегда помнить.
  + 🔒 В связи с этим рекомендация:
      - **Используйте RSM только в своей домашней/доверенной сети.** 
      - **Никогда не открывайте в RSM почту, госуслуги, соцсети, любые сайты с чувствительной для вас информацией где вы вводите пароли, платёжные данные, 2FA-коды и т.д.**
      - Не подключайтесь к чужим незапароленным сетям (это общий совет, к RSM не относится, но все же нужно помнить)
      - Ну и классичесское: Автор **не несет ответственности** за любые последствия использования RSM для доступа к непредназначенному контенту (фишинг, кража сессий, утечка данных и т.д.). <br>Используйте RSM только для доступа к своим устройсвам в своей сети!
